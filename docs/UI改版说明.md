## 头像分身分步创建

上传与裁切头像 → 外观（默认保持原貌，可选女性、男性） → 身形与站姿 → 生图预览 → 确认。外观参数在服务端校验并进入生成提示词；确认后保存设置。支持返回修改与生成后调整，缺少有效照片时禁止继续。全身照直接确认流程保留。分步界面、返回修改、保存与后续试穿回归检查通过；服务端模拟测试覆盖所有外观参数及无效值拒绝；云端完成界面与接口校验。本轮无付费生图。

衣橱推荐尚未实现，后续从用户真实上传的全部衣物中按类别、偏好和场景筛选组合，用户选定后再生成试穿。

## 二维白模实验原型

独立入口 /body-lab/。固定正面站姿，参数为肩宽、腰腹宽度、臀宽与上下身比例，支持预设、保存、重置、导入导出与无标记 PNG。六种白模各做两次真实生图，共 12 张。结果在 /body-lab/experiment/，输入与原始结果全部展示。当前模型没有稳定跟随输入的明显比例差异，因此未将参数接入正式分身生成。原型在设备本地运行，无付费生成按钮。

## 采用身形描述生成

按用户决定停用白模选择与所有实验入口，原型移出 APP 并保存在本地实验目录归档。分身生成仅上传人物照；整体体型、肩部、腰腹、臀部、上下身比例、可选身高与站姿由服务端固定配置映射到版本化提示词。局部选择只覆盖对应区域，生成前展示确认摘要。头像和全身照均可使用描述生成；全身照另保留直接确认、不调用生图的路径。设置快照、提示词版本和摘要哈希与生成任务关联，确认后保存在本地分身记录中。它们是生成目标，不保证模型精确遵循。模拟与真实 HTTP 校验通过，本轮没有付费生图。

## 账号、分身库与图片保存

增加账号卡、真实的免费分身额度、分身库与切换/删除/导出；没有分身时显示明确空状态。统一分身、试穿、OOTD 导出水印，下载链接未配置时只显示 APP 即将上线。成功扣次数、删除不返还；短信尚未配置时明确禁用发送，不提供模拟验证码。本机隔离测试和云端无付费生图检查通过，真实 iPhone 保存分享仍需真机验收。
