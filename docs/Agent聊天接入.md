# Agent 聊天入口

电脑端（宽度 ≥1024px）右侧常驻聊天栏，进入页面自动显示，不需要点击，也不提供收起按钮。主工作区预留空间；1600px 以下主内容按单列排列，避免挤压。窄屏保留按钮与覆盖面板。不增加主导航。聊天记录按当前浏览器身份独立存入 localStorage；清理浏览器数据将丢失记录。不会自动发送照片，衣橱文字信息由用户勾选后附带。

当前是文字对话助手，不是已具备工具执行能力的完整 Agent。不能自动生图、删除衣物或保证尺码合身。工具调用、持久任务与执行确认属于后续开发。

## 自部署配置

在启动服务的进程环境中设置：

- TRYON_LLM_URL：兼容 Chat Completions 的完整接口 URL。
- TRYON_LLM_MODEL：服务商或本地模型的模型 ID。
- TRYON_LLM_KEY：接口要求的密钥，本地无认证服务可不填。

例如本机提供兼容接口时，可设置 URL 为 http://127.0.0.1:11434/v1/chat/completions，模型 ID 必须是本机实际安装且支持聊天的模型。配置后重启 Python 服务。远程服务使用 HTTPS；不要把密钥提交 Git 或写进前端。当前没有网页编辑密钥的入口。LLM 配置与现有 Seedream/fal 生图配置分开。

## 验证边界

10 项单元测试通过。隔离浏览器验证未配置禁用发送、模拟回复、刷新恢复记录，以及 1920、1366、390 宽度无横向溢出。没有真实 LLM 调用，没有付费生图，没有部署线上；不能将模拟测试视为真实模型联调通过。
