# 双模型选择 · 2026-11-06

按用户要求同时保留 fal.ai Nano Banana 2（fal-ai/nano-banana-2/edit）与火山方舟 Seedream 5.0 Flash（doubao-seedream-5-0-flash-260915）。分身创建表单和试穿页均提供选择器，两处同步，默认 Seedream，偏好保存在当前浏览器。无需短信登录。

local/generation.py 是唯一服务端路由表，POST /api/avatar、/api/try-on 的 provider 参数只允许 seedream 或 fal。缺失时按默认 Seedream 处理，未知值拒绝。不可用模型不自动回退，避免未经用户选择的供应商发送与重复计费。GET /api/avatar/options 返回两家模型 ID、显示名称及配置状态，不返回密钥。

分身请求将 provider 纳入客户端请求摘要与服务端设置记录；试穿任务保存提交时的 provider 和 model，继续查询原任务不会因选择器变更改用其他模型。任务执行期间不允许切换。两个成功分身额度按浏览器身份共用，切换模型不增加额度。

服务器保留 FAL_KEY 和 ARK_API_KEY；fal-client 已安装，requirements 恢复其依赖。本地启动器分别支持 .secrets/fal.key、.secrets/ark.key 的 DPAPI 加密配置；未配置的一家在界面禁用，不公开密钥。

验证：8 项隔离测试通过，包括两条适配路径、无自动回退、未知模型拒绝，以及 HTTP 分身流程跨模型共用两个名额。公网两家 ready 均为 true；移动尺寸浏览器验证两处选择同步、刷新保留，分身提交 fal、试穿提交 seedream；提交请求被测试浏览器拦截，未调用付费生成，未写入模拟生成图片。此前单独的真实模型验证不等同于本轮双模型换装质量对照。
