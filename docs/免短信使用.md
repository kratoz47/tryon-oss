# 免短信使用 · 2026-11-06

用户明确要求删除当前短信登录要求，已更新并上线 https://tryon.example.com。

首次 /api/me 自动创建随机浏览器身份并发放 HttpOnly、SameSite=Lax、HTTPS Secure Cookie，有效期 365 天。它不是电话号码或可跨设备登录的账号。已有有效身份会继续使用，原有资料和额度保留。浏览器旧访客衣橱会在首次身份关联时复制到该身份的本机存储，不主动删除原记录。

免费分身仍在服务器按身份统计两个成功名额，失败释放、删除不返还；分身图片仍校验所属身份，不能因此公开其他人的照片。清 Cookie、会话过期或换设备可能失去资料关联并创建新身份，因此不能保证每个自然人只有两个免费名额，也不承诺跨设备恢复。

页面移除手机号表单、登录弹窗及退出登录入口；/api/auth/ 下原短信接口返回 410，不会发送验证码。试穿、分身创建、分身切换和下载继续使用。模型保持 Seedream 5.0 Flash。没有为取消登录增加无限生图承诺。

测试：隔离 HTTP 测试使用模拟生成，验证自动身份、Cookie 持续、身份隔离、两个成功名额和第三次拦截。连同模型适配测试共 5 项通过。公网移动尺寸浏览器验证首次打开自动建立身份、刷新身份不变、身形设置走到生成按钮无需验证码、无登录弹窗、无 JS 错误；测试没有付费生成图片。未宣称完成 iPhone 真机测试。
