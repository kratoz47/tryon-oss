# 电脑网页布局优化

2026-11-10，按用户最新要求，电脑网页布局优先；覆盖旧文档中的手机优先视觉方向。当前修改仅在本维护目录，未部署线上。

- 1024px 及以上使用固定左侧四导航，主工作区随屏幕展开。
- 试穿：人物展示与右侧操作面板并排，六个服饰入口加大，生成按钮首屏可见。
- 分身：人物与信息操作分列，人物高度适配浏览器窗口。
- 衣橱：压缩宣传区，统计并排，上传表单横排，衣物使用自适应多列网格。
- 电脑上的选择弹窗居中展示，窄屏仍保留原布局。

验证：8 项现有单元测试通过；隔离浏览器检查 1024×768、1366×768、1920×1080、390×844 下五个页面无横向溢出和 JavaScript 异常。桌面试穿生成按钮位于首屏、六类入口保留。没有调用付费生图。截图位于 ui/desktop，人物为测试占位插图，不是生成结果。尚未部署，不能视为线上验收。
