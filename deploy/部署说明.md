# 独立服务器内测部署（systemd + Nginx）

应用目录 /opt/tryon，Python 3.10+，推荐已安装的 Python 3.11。安装 deploy/requirements.txt。APP_ORIGIN 为实际 HTTPS 域名，ARK_API_KEY 仅放服务端 /etc/tryon/tryon.env。使用独立 Nginx 站点，反代 localhost:8765，覆盖 Host、X-Forwarded-Proto、X-Real-IP。不要改动其他站点。

服务以 www-data 用户运行。/var/lib/tryon 为 700 的私人持久目录，不能放进 web 目录。新部署可使用 install.sh；现有部署先检查并备份，不要覆盖原配置或私人数据。systemd 模板限制 220 MiB、32 任务，串行生图，仍需观察真实负载。

本版本没有浏览器 Basic Auth。AI 分身生成由手机号账号和服务端 2 次免费额度控制，实际登录需短信签名、模板和服务端授权就绪；详见“短信与分身额度接入.md”。SMS 未配置时不会用模拟验证码。

下载二维码地址由 SHIYI_APP_DOWNLOAD_URL 控制，上架后补充，空配置仅显示待上线文字，不放假二维码。当前仍为封闭内测，非正式上架版本。
